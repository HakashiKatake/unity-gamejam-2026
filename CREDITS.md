## Audio

The imported project contains no audio recordings. `GameConfig` has optional fields for cast, impact, chip, reel, jackpot, damage, and boss clips. Assign only human-recorded or appropriately licensed non-generated audio. Empty fields are handled safely without synthesizing substitute sounds.

## Jam AI disclosure

AI tools assisted with game design, C# programming, editor automation, shader code, UI layout, testing, and build preparation. Character sprites, icons, slot-machine art, and backgrounds came from pre-existing imported asset packs credited above. No generative image or audio model was used to create media for this submission.
